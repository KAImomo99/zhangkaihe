# 慢慢 · 照片故事平台

这是可下载运行的完整平台源码，不是 Skill 或演示截图。

**选照片 → 排顺序 → 标时间 / 选章节 / 讲故事与精修 → 预览 → 成片导出与版本库**

## 下载和运行

下载 [完整平台源码包](./manman-story-platform.zip) 并完整解压。不要直接双击 dist/index.html，浏览器功能需要通过 HTTP 访问。

需要 Python 3；不需要安装 Python 包、npm 依赖或编译。

- macOS：在解压目录运行 `python3 start.py`；也附带 `启动平台.command`。
- Windows：在解压目录运行 `py -3 start.py`；也附带 `启动平台.bat`。
- Linux：在解压目录运行 `python3 start.py`。

启动后会打开 **http://127.0.0.1:4317/**。保持终端运行，按 Ctrl+C 停止。若启动脚本被系统阻止，可在终端执行上面的 Python 命令，不必改变系统安全设置。

## 已实现

1. 文件夹或多图导入，支持 HEIC/HEIF、JPG、PNG、WebP、GIF、AVIF、BMP；读取拍摄日期，保留格式转换副本和原文件。
2. 拖动排列照片，确认后保留手动顺序，后续补日期不会悄悄重排。
3. 标时间、选相识/相恋/准备婚礼，记录照片背后的故事；逐图对照原稿与润色文案、修改、确认、恢复旧稿。
4. 时间轴拖动、点击照片定位、字幕逐行显示、添加本地配乐和浏览器预览视频导出。
5. 下载交给 GPT-6 的剪辑制作包，导入已有 MP4/WebM/MOV，播放、下载并记录版本备注。

## 需要注意的实际边界

- **在线 AI 润色尚未接入模型服务**。当前导出 JSON 润色请求，交给模型生成后导回精修；代码没有内置 API Key。
- **口述转文字取决于浏览器支持、麦克风权限和语音服务**，不可用时可以使用系统听写或键盘输入。录音本身不等于转写。
- **正式成片通过制作包交接**，不会自动提交给 GPT-6。网页能生成 720p MP4 或 WebM 预览，具体格式取决于浏览器；正式高分辨率成片需另行渲染。
- 此版本预览是一张照片一页；多图组合排版需在正式剪辑阶段完成。

## 照片和历史视频在哪里

照片、标注、音乐和成片都保存在**当前地址、当前浏览器**的 IndexedDB 中，不会自动上传或跨设备同步。

线上平台已有的数据不会自动出现在下载版。迁移时先在原平台导出标注备份和素材/成片，再在下载版导入原照片、恢复标注、加入历史视频。

请固定使用 `http://127.0.0.1:4317/`，不要交替使用 localhost、不同端口或不同浏览器；这些地址的数据互相隔离。换设备或清理浏览器数据前，先导出备份。代码包中没有私人照片、故事、录音或历史成片。

## 部署给其他人使用

把 **dist/** 的内容部署到 HTTPS 静态网站服务即可。每位访客的数据保存在自己的浏览器；这不是共享云相册。在线润色、账户和云端素材存储需要另行配置后端。

使用 GitHub Pages 时需要先将 dist 中的实际文件解压到对应发布目录；仅上传 ZIP 不会自动变成在线站点。

## 源码与测试

- dist/：全部页面、脚本、样式和离线分发的图片格式解码依赖。
- tests/：日期、排序、文案导入、时序、导出和版本规则测试。
- start.py：只监听本机的启动服务。

安装 Node 后，在项目目录运行：

```sh
node --test tests/*.test.mjs
```
